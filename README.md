# دعوت‌نامه دیجیتال عروسی امید و یلدا

یک سایت تک‌صفحه‌ای و کاملاً استاتیک (HTML + CSS + جاوااسکریپت ساده). بدون فریم‌ورک، بدون مرحله‌ی build و **بدون هیچ درخواستی به سرویس‌های خارجی** — فونت، تصاویر و موسیقی همه روی سرور خودتان است.

## ساختار پوشه‌ها

```
index.html               صفحه‌ی اصلی
css/style.css            استایل‌ها
js/main.js               منطق صفحه + شیء CONFIG (همه‌ی اطلاعات قابل ویرایش)
assets/fonts/            فونت وزیرمتن (woff2)
assets/gallery/          عکس‌های بهینه‌شده (WebP)
assets/gallery/raw/      عکس‌های اصلی شما (در گیت ذخیره نمی‌شوند)
assets/music.mp3         موسیقی پس‌زمینه
assets/og.jpg            تصویر پیش‌نمایش لینک در واتس‌اپ/تلگرام (۱۲۰۰×۶۳۰)
scripts/optimize-images.js  اسکریپت تبدیل عکس‌ها به WebP
deploy/nginx.conf        تنظیمات Nginx
```

## ویرایش اطلاعات

همه‌ی متن‌ها، تاریخ و ساعت، مختصات و لینک‌های مسیریابی، فهرست عکس‌ها و مسیر موسیقی در شیء `CONFIG` در **ابتدای فایل `js/main.js`** هستند. فقط همان‌جا را تغییر دهید.

- مختصات تالار (`CONFIG.venue.lat` و `lng`) تقریبی است؛ آن را اصلاح کنید. لینک بلد و گوگل‌مپ خودکار از روی مختصات ساخته می‌شوند.
- تگ‌های پیش‌نمایش لینک (og:title و …) در `<head>` فایل `index.html` هستند، چون واتس‌اپ و تلگرام جاوااسکریپت اجرا نمی‌کنند.

## اضافه کردن عکس‌ها

۱. عکس‌های اصلی (jpg / png / heic / …) را در پوشه‌ی `assets/gallery/raw/` بگذارید. ترتیب نمایش بر اساس نام فایل است (مثلاً `01.jpg`، `02.jpg`).

۲. یک بار وابستگی‌ها را نصب کنید (Node.js 18 یا بالاتر لازم است):

```bash
npm install
```

۳. اسکریپت بهینه‌سازی را اجرا کنید:

```bash
npm run images
# یا: node scripts/optimize-images.js --quality 80 --clean
```

برای هر عکس دو فایل WebP ساخته می‌شود: `name-600.webp` (بندانگشتی) و `name-1600.webp` (تمام‌صفحه). در پایان، یک تکه کد `gallery: [...]` چاپ می‌شود؛ آن را جایگزین `gallery` در `CONFIG` کنید. عکس‌های افقی خودکار `wide: true` می‌گیرند (تمام عرض). متن `alt` هر عکس را هم می‌توانید ویرایش کنید.

۴. فایل‌های `placeholder-*.webp` را از `assets/gallery/` پاک کنید.

## موسیقی

فایل خود را با نام `assets/music.mp3` جایگزین کنید (فایل فعلی فقط یک صدای نمونه است). پیشنهاد: ۱ تا ۳ دقیقه، ‎128kbps، حجم زیر ۳ مگابایت. موسیقی با همان لمسِ باز کردن پاکت پخش می‌شود و تکرار می‌شود. اگر فایل نباشد، دکمه‌ی موسیقی خودبه‌خود مخفی می‌شود.

## تصویر پیش‌نمایش (og.jpg)

`assets/og.jpg` یک نمونه‌ی ساده در سبک سایت است. اگر تصویر دیگری می‌خواهید، فایلی **۱۲۰۰×۶۳۰ پیکسل** و ترجیحاً زیر ۳۰۰ کیلوبایت با همین نام بگذارید.

پس از انتشار، در `index.html` مقدار `og:image` و `twitter:image` را به آدرس کامل تغییر دهید، مثلاً:

```html
<meta property="og:image" content="https://invite.example.ir/assets/og.jpg">
```

## اجرای محلی

```bash
npm run serve        # سپس http://localhost:8080
# یا
python3 -m http.server 8080
```

## تست شمارش معکوس (شبیه‌سازی زمان)

با پارامتر `?now=` در آدرس، زمان «حالا» را شبیه‌سازی کنید:

| حالت | آدرس |
| --- | --- |
| قبل از روز مراسم | `http://localhost:8080/?now=before` |
| روز مراسم، قبل از ساعت ۷ (نمایش «امشب شب ماست ✨») | `http://localhost:8080/?now=today` |
| بعد از شروع مراسم (پیام تشکر) | `http://localhost:8080/?now=after` |
| زمان دلخواه | `http://localhost:8080/?now=2026-10-19T18:59:50%2B03:30` |

(در زمان دلخواه، `+` را به شکل `%2B` بنویسید.) همین کار را با مقداردهی `CONFIG.debugNow` هم می‌توانید انجام دهید — **قبل از انتشار آن را `null` بگذارید.**

شمارش معکوس همیشه نسبت به زمان مطلق `2026-10-19T19:00:00+03:30` (ساعت تهران) محاسبه می‌شود و به منطقه‌ی زمانی گوشی مهمان بستگی ندارد.

## انتشار روی سرور (Nginx / پنل پاچیم)

۱. این فایل‌ها و پوشه‌ها را در پوشه‌ی سایت روی سرور آپلود کنید (مثلاً `/var/www/omid-yalda-invite`):

```
index.html  robots.txt  css/  js/  assets/   (بدون assets/gallery/raw)
```

با rsync:

```bash
rsync -avz --delete --exclude 'assets/gallery/raw' \
  index.html robots.txt css js assets user@SERVER:/var/www/omid-yalda-invite/
```

یا از بخش مدیریت فایل پنل پاچیم، فایل zip را آپلود و از حالت فشرده خارج کنید.

۲. محتوای `deploy/nginx.conf` را در تنظیمات Nginx سایت در پنل قرار دهید (یا در `/etc/nginx/conf.d/`). در آن فایل `invite.example.ir` را با دامنه‌ی خودتان و مسیر `root` و گواهی SSL را اصلاح کنید.

۳. بررسی و اعمال:

```bash
sudo nginx -t && sudo systemctl reload nginx
```

۴. **بعد از هر تغییر در `css` یا `js`**: چون این فایل‌ها ۳۰ روز در مرورگر کش می‌شوند، در `index.html` عدد نسخه را بالا ببرید (`style.css?v=2` و `main.js?v=2`). خود `index.html` کش نمی‌شود.

۵. لینک را یک بار در تلگرام/واتس‌اپ برای خودتان بفرستید تا پیش‌نمایش را ببینید. (تلگرام پیش‌نمایش را کش می‌کند؛ برای به‌روزرسانی از ربات ‎@WebpageBot استفاده کنید.)
